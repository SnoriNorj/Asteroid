# Asteroids (Python + Pygame)

A clone of the classic Asteroids arcade game built with Python and Pygame.

## Purpose

Shoot asteroids before they hit you. Large asteroids split into smaller,
faster ones when destroyed. Survive as long as you can.

## Requirements

- Python 3.11+
- [uv](https://github.com/astral-sh/uv) (recommended) or pip

## Installation

```bash
# Clone the repo
git clone <your-repo-url>
cd <project-folder>

# Install dependencies
uv sync
# or: pip install pygame
